`src/server.ts` mirrors calc-service's: a `start(env)` that serves the app through `@hono/node-server` on the resolved port and resolves to the bound port plus a `close()`, with the entry-point block guarded by `import.meta.main` so importing binds nothing. The real client is built here from the resolved config and global `fetch` — the one place production wiring is assembled, and the only module with no injection seam of its own (AC-18). `package.json` gains its two entry-point scripts here, with the file they point at: `dev` is `node --watch src/server.ts` and `start` is `node src/server.ts`, as calc-service's are (subtask-2 says why they were held back).

Its test binds a free port for real, as Phase 1's does: the announced port is the bound port, the service answers there and nowhere else, and it releases the port when stopped. There is no fake in it — `start(env)` builds the real client from the environment with no seam to inject one, and `spec.md` § Approach rules out patching `globalThis.fetch`. Instead the test points `CALC_SERVICE_URL` at a port nothing is listening on and asserts what that produces: `400 VALIDATION_ERROR` for a malformed body (the path needing no downstream) and `502 SERVICE_UNAVAILABLE` for a valid one, deterministic in about 100 ms because a refused connection fails immediately and is retried once. That is the real wiring end to end — config, client, deadline, retry, classification, route — and doubles as the live check of AC-15's unreachable path. `CALC_SERVICE_TIMEOUT_MS` is set small so no case approaches three seconds. No calc-service process is started, and the entry-point case spawns `node src/server.ts` as a child with the same environment to assert the announce, as Phase 1's does.

`apps/api-gateway/README.md` (AC-19) states that this is the only public service and the only address the SPA will ever know, the start and test commands, the four variables from `spec.md` § Configuration with their defaults, and worked `curl` examples for a success, a 400, a 422 and the 502 a reviewer sees after stopping calc-service (UC-7). AC-20 is the workspace-level gate: the root `lint`, `check-types`, `test` and `build` tasks stay green with the new workspace present, and `npm run dev` — green for every workspace only from this subtask, since the scripts it runs land here — starts both services side by side.
